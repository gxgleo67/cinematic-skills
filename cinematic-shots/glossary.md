# 术语表（按拼音排序）

5 本书合并去重，别名写进括号。出处缩写：v1/v2/v3 = 第1/2/3卷，sp = 斯皮尔伯格篇，tq = 昆汀篇，c5 = 第5章。

**B**｜**半圆绕行**（等距环拍）— 恒定距离绕一整圈，途中必有一刻正对眼睛 (v2c2)｜**边界空间** — 室内外交界处，人物归属不明，自带监视压力 (v2c3)

**D**｜**单镜头象征** — 只有不剪的推拉升高能让"两人分开"成立 (v2c8)｜**等速推近** — 两机同速靠近、同步变大，剪开即"共同靠近" (v2c5)｜**等距贴身跟拍** — 距离高度角度全不变的跟随，产生现场体感 (v1c2)｜**赌注可视化** — 把"赶不到会怎样"拍成画面 (tq6)｜**动机**（走位理由／动作挂钩）— 移动的画内借口，缺失即暴露导演 (v1c8, v3c11)

**F**｜**反定场** — 把空间交代藏进动作与细节，观众不觉 (v3c6)｜**反高潮** — 拉满后给落差泄压，或取消预期高潮 (sp6, tq7)｜**方位锚点** — 始终可见的人或物，维持多机位方向感 (v3c11)

**G**｜**故事点序列** — 必须看到的信息及其顺序，设计的起点 (v3c11)

**H**｜**后景接力** — 逃跑者出画时主角在同景深补位，避免剪断追逐 (sp1)｜**后拉揭示** — 机器静止表僵局，缓退让人变小再纳入旁人 (tq11)｜**画外空间** — 画面外被想象、在交付时爆发的空间 (v1c7)｜**荷兰角**（倾角）— 侧倾即失衡，归零即回现实 (v2c3)

**J**｜**机位高度即立场** — 与谁等高，观众就站谁那边，双机须同高 (v1c9)｜**机位高度背叛** — 高度不属于任何人，专造不适，一场一次 (v2c2)｜**机位距离差** — 谁离机器近，观众就站谁身上 (v2c7)｜**机位经济** — 减机位以集中表演，赔上剪辑选择 (v3c8)｜**假动作**（借位）— 靠景别遮挡剪接音效造假，无需接触 (v1c1)｜**假想轴线**（中心线）— 两演员间隐形连线，机器默认只在一侧 (v2c1)｜**剪影** — 只剩轮廓；脸缺席而身形在场才有神秘感 (v3c9)｜**焦点交棒**（移焦）— 用转焦而非剪切交接注意力与话语权 (v1c6)｜**焦平面即关系** — 同焦平面相连，落焦外即断开 (v3c5)｜**近即权** — 离机器更近的人默认掌握局面 (v3c5)｜**距离欺骗** — 用运动突然终止取消观众预估的距离 (tq6)

**M**｜**镜像构图**（镜像双人）— 借玻璃同框拍两人替代正反打，表情会削弱 (tq5)

**Q**｜**前景掠过** — 从机器前擦过的柱、墙、人，最便宜的运动感 (v3c7)

**S**｜**三层景深** — 前中背景同时可读，静态镜头才有内部剪辑 (v3c3)｜**视点复制** — 复刻演员刚完成的动作伪造主观视点 (v3c3)｜**视觉入侵** — 不受欢迎者反复侵入主角空间 (tq4)｜**速度参照物** — 速度感来自掠过镜头的近景 (v3c2)｜**速度差** — 机器与演员速度之差造成跟丢或突破 (sp1)

**T**｜**特写平衡** — 给了强者必给弱者，否则读错力量关系 (tq7)｜**同机位跳切** — 机位不动只换长焦，重复构图锁空间记忆 (tq3)｜**跳接**（小角度剪接）— 近似视角互跳，全靠动作一致 (v2c9)

**X**｜**象征物** — 可被亲手移开的实体，把隔阂变成动作 (v2c11)｜**两种恐惧** — 悬疑＝观众知道更多；惊吓＝不更多 (v1c4)

**Y**｜**一次不剪** — 连贯镜头优先于剪辑 (v1c6)｜**一镜多机位感** — 由分层与交叉走位造成的多角度错觉 (sp7)｜**延迟揭示**（延迟给脸）— 只给局部、压后给全 (sp4)｜**越轴** — 切到连线另一侧，赔空间秩序换焦虑 (v2c1)

**Z**｜**张弛波** — 紧张与松弛交替，悬念的载体 (sp6)｜**遮挡转场** — 用门、柱、人群遮住画面换人或换空间 (v1c3)｜**主镜头** — 交代全员位置与势力的全景 (tq9)｜**转向动机** — 每次转向回头都要有画内理由 (v2c7)
