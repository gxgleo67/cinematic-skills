# 决策速查

## 一、解法阶梯
1. **改演员走位** — 表演与关系是重点时用；代价是排练时间
2. **加机位运动（须有动机）** — 要观众"感到"而非"知道"
3. **剪切／覆盖** — 前两层都无法一次完成

**规则**：能从第 1 层解决就别用第 3 层；覆盖是保险，不是设计。

## 二、对话戏机位决策树
1. **必须同框才说得清关系？** → 同框双人中特写（身体朝相反、视线错开）；还想要剪辑感，改**小角度跳接**
2. **不该直视对方？** → **镜像双人**（玻璃前拍，移焦交权）
3. **超过两分钟？** → **走位代替反打**（绕行转身，转身卡在转折且有动机）
4. **只能正反打？** → **等速推近**（只推一边＝单方施压）
5. **要观众不适、觉得谁在说谎？** → **越轴**（须有背对的物理理由）或**机位高度背叛**（一场一次）
6. **要孤独/异地？** → **背后观察者**（静止长焦、前景隔开、不给脸）

## 三、张力不够时按序试
- 只是"躁"不是"紧" → 停止切碎，改**视觉入侵接力**（一次一条，逐次更近）
- 威胁迟迟不来 → **空镜等待**＋**威胁先露一面**
- 拉满后撑不住 → **反高潮泄压**，随即种新疑点
- 破坏没力度 → 缺**基线**，先回开场构图再拆掉它
- 惊吓不响 → 缺**安全承诺**或**情节理由**
- 转折说不清 → 信息落地没有**可见位移**

## 四、权衡矩阵
| 方案 | 换来 | 赔上 |
|---|---|---|
| 长焦 | 一张脸、压迫、逃不掉 | 环境信息、空间关系 |
| 广角 | 速度、混乱、空间 | 假打与借位全部暴露 |
| 少机位 | 表演集中、象征成立 | 剪辑选择变少 |
| 多机位覆盖 | 安全网、基线素材 | 戏变散、能量下降 |
| 一镜到底 | 代入、微差可读 | 走位与时间必须精确 |
| 特写 | 读懂内心的一秒 | 稀缺性，用多即失效 |
| 高度转移 | 不靠台词反转权力 | 全场须统一，一次为限 |
| 遮挡/假动作 | 零风险的真实暴力 | 每镜必须极短 |

## 五、经验默认值
| 参数 | 默认做法 |
|---|---|
| 推轨距离 | 至少 3 米，推几步就停＝白搭一条轨 |
| 高度差 | 半米即可翻转权力感，不必让人站起来 |
| 眼神焦点 | 假墙/假窗旁必须放真实可聚焦物 |
| 节奏建立 | 同向横摇 2–3 次最佳，3 次以上观众开始预判 |
| 转折前静止 | 3–5 秒；超过 8 秒从紧张变等穿帮 |
| 特写配额 | 每场 1–2 个；给了强者必须给弱者 |
| 运动配额 | 一场 1–2 次（后拉/环绕/前推），只用在转折与权力交接 |
| 多人场方位 | 前 10 秒交代座位，之后留一截衣袖作锚点 |
| 同一招频次 | 反高潮、高度背叛、反转仰拍：一场各一次 |

## 六、快速识别信号（tells）
- **看出导演在动** → 机器运动缺画内动机
- **读不出强弱** → 两机高度混用，或距离差没做
- **画面发平** → 缺前景，缺三层景深
- **观众头晕** → 越轴没有理由，或倾斜未归零
- **情绪起不来** → 全片都在动、没有静止参照；或信息一次给完
- **演员在"摆位置"** → 走位缺动机，不如老实切反打
- **长镜头像素材带** → 起幅与落幅太像，等于没运镜
