# 第11章：创意场景（《大师镜头 第2卷》）

## 核心思想
前几章都在回答"用什么技巧"，这一章回答"怎么发明技巧"：找出一个日常动作（转身、弹琴、端东西、走过房间），把机位挂在这个动作上，让它替你说出关系。创意的单位不是构图，而是"动作＋机位"的组合。

## 技巧框架
- **转身（11.1）**: 让一个人转过一个不大的角度，把路过的过肩镜头变成有矛盾的双人镜头。
  - 何时用: 背景里正在发生事情（上船、集结、人群），而对话需要并置。
  - 怎么做: 开场两人都望着背景中的活动；其中一人转开视线、不再看背景——这个转身就是他不想参与的证据；不给传统过肩，而是给一个双人中特写，两人身体朝相反方向、头各倾一点，于是两张脸都在画面里；身体朝向相反＝有矛盾，回避对视＝不是真心交流。
- **动静突变（11.2）**: 用一次摇拍＋演员起身离座，把坏消息的冲击变成空间变化。
  - 何时用: 消息对接收者极重要，而传达者毫无察觉。
  - 怎么做: 机位与坐着弹琴的人同高，另一人从身后走来；关键信息出现时，传达者停步，弹琴者起身向前走；摄影机保持低位，只跟着她摇，同时微微上仰并向侧边让开一点，让她始终居中；上仰给她权威感，侧移让观众觉得"自己也退开了半步"；她走开后自然背对传达者，把情绪藏起来。
- **后退（11.3）**: 摄影机持续后退，随发言次序把桌边的人一个个揭示出来。
  - 何时用: 会议、长桌讨论，人物多而你想一句话一个人。
  - 怎么做: 让每个人手头都有事忙（这是本书反复强调的要诀），且说话时都不看别人；摄影机快速后退（本例很快，你的片子里可以放慢），谁发言就把谁带进画；这个思路可以推广到任何需要依次揭示的场合。
- **特殊角度（11.4）**: 找一个不寻常的地点，逼出非常规的身体关系，从而获得不平等的视线。
  - 何时用: 对话简单，你想让观众专心听，又不想用正反打。
  - 怎么做: 先用广角交代两人的位置关系；再切近景，因为位置特殊，一人必须转头才能看到对方，另一人却可以一直盯着她——于是第一个人处在被审视、略微脆弱的位置；给其中一人一点食物之类的活计，让她有话可做；实在想不出，就问演员本人，但要准备备选方案。
- **在不同房间（11.5）**: 先同处一室，再让一人走进另一个房间，把对话跨过门槛。
  - 何时用: 两人关系不该疏远，但对话需要"换个空间"而不中断。
  - 怎么做: 开场两人同房间交谈并交叉走过镜头；一人走进另一个房间，观众以为场景结束，对话却继续；让留下的人从镜子里看到对方——他人在背景里、占画面很小，但通过镜中的视线仍是焦点；必要时结束镜中把戏，让人从墙角探出半个身子。
- **远景移位（11.6）**: 摄影机在远处横向移位，让每个角色依次从空间中浮现。
  - 何时用: 对话重要，但你想让角色被环境压小、显得被困住或被监视。
  - 怎么做: 在走廊／封闭通道里横向移动机位，人物逐个进入视野；声音保持清晰，仿佛观众就在旁边，视觉上却隔得很远；移到某个位置停住，对话继续，直到第三人加入；必须有移位，纯远景不够——移位才产生"偷窥"的意味；利用墙角线把视线引向他们的位置。
- **调转镜头（11.7）**: 制造一个明确的期待，然后让演员转身，永远不给观众想看的东西。
  - 何时用: 观众被吊起好奇心（柜子里有什么、门外是谁），你需要延迟揭示。
  - 怎么做: 先让两个小孩前倾身体盯着柜子，把期待建立起来；然后让一个人走过来、转身说话，机位几乎在她正上方；观众只看到柜子里的一些无关之物，紧张因此缓解；面对镜头的演员不能看镜头（否则会变成柜中之物的主观视角），并且必须给他们一个具体可看的落点，否则三条视线会各看一处。
- **穿过整个场景（11.8）**: 用一个角色横穿房间，决定谁是主角、谁是附属。
  - 何时用: 一场戏要确立主角在整部片中的位置。
  - 怎么做: 开场让她在画面正中忙碌（冰箱、宠物），只给另一个人声音，不给他镜头；她向前走、从另一人身边经过，让观众只瞥到对方一眼——比完全不露脸更能表明他无足轻重；她背对他坐下，只把头顶转出一个角度让观众看到她的脸，同时把他挤出画面，于是"同处一室仍孤独"；最后一个镜头机位与男方同高，把观众从她的世界里略微拉出来。
- **角色的现身（11.9）**: 摄影机不动，靠背景人物走开让新的背景人物浮现。
  - 何时用: 你想加深景深，同时把焦点锁在主角身上。
  - 怎么做: 机位略低于主角视线并微仰，观众因此不被她手上忙碌的动作打扰，还能看到背景人物的脸；背景人物上前来而主角不转头看她，注意力就仍在主角表情上；随后略微推近（或略微下俯），背景第一人走开，第二人接着谈；更换背景人物时，动作要与离场时机吻合；反复进出可加强效果，但主角必须是最强光、占最大画面。
- **插到中间拍摄（11.10）**: 把摄影机推到两人之间，用物理介入替代反打。
  - 何时用: 地点本身是故事的一部分，或两人之间正出现问题。
  - 怎么做: 开场两人在画面左下，他们注视的地方和他们一样重要；摄影机前推，两人转头相对，此时机位向右调转，重点拍到主角的反应；接着摄影机插到两人之间，画面只剩主角一人，由他独自说完台词。这个"插入"比来回切换更能让观众感到冲突。
- **消除隔阂（11.11）**: 在两个演员之间放一个象征性的物件，再让它被移开。
  - 何时用: 两个角色的隔阂需要一个可拍、可破的实体。
  - 怎么做: 用长焦让两人中只有一人合焦，前景人物的动作仍可见，注意力却在合焦者身上；把垂下的胶卷条安排在他们之间，像牢笼的栏杆；当他走向她时，伸手把胶卷拨开——障碍被亲手移除；随后切广角，两人靠近、居中，他挡住身后的窗户，那只作为"隔阂标记"的玩偶随之消失。

## 关键概念
- **动作挂钩**: 机位运动必须挂在一个具体动作上（转身、起身、拨开胶卷），否则显得随意。
- **身体朝向相反**: 头互相倾斜一点、身体各朝一边，是"有矛盾但仍同框"的最佳结构。
- **等待—延迟—缓解**: 制造期待、不给答案、让紧张自然泄掉，比直接揭示更耐看。
- **象征物**: 一个可被移开的实体，把"隔阂"从抽象变成可拍的动作。
- **空间主权**: 谁在画面正中、谁占最强光、谁挡住谁，就是这场戏的权力排序。
- **可预计的未来**: 摄影机在远处移位时，观众会预感它要停在哪，这个预期本身就是张力。

## 心智模型
- 想发明一个新机位，先找场景里现成的日常动作，把镜头绑上去。
- 当你想表达冲突，别只在两人之间切，把摄影机插进去。
- 把横向移位当作"揭示次序"的工具：谁被带进画，谁就是此刻的主角。
- 想要一个场景有余味，就让观众期待的东西永远不出现。

## 反模式
- **为创意而创意**: 机位运动没有动作依据，观众只会看到摄影机在表演。
- **远景只有远、没有移位**: 失去偷窥感与气场，只剩"看不清"。
- **让面对镜头的演员看镜头**: 立刻变成主观视角，语调全变。
- **不给演员固定的视线落点**: 三条视线各看一处，剪起来对不上。
- **象征物一直留在原地**: 隔阂被摆出来却没人去破，观众会觉得被耍。
- **背景人物换场不与主角动作吻合**: 新人物凭空出现，深度感变成混乱。

## 实例解析
《蒂凡尼的早餐》（11.8 穿过整个场景）：赫本在画面正中忙碌于冰箱和一只猫，男方只有声音、没有镜头——她才是主角。她向前走、从他身边经过，观众只瞥到对方一眼，比完全不露脸更能说明他无足轻重。最后她背对他坐下，只把头转出一个刚好让观众看到脸的角度，同时把他挤出画面：两个人在同一个房间里，她却是孤独的。机位在最后一刻仍与男方同高，于是观众被轻轻从她的世界里带出来半步。

## 结语：把技巧交给演员（本书结语）
这些设计一定会遇到阻力，主要来自演员，其次是制片方。化解办法只有一条：让演员确信，这些调度是为了拍到他们最好的状态。开拍一两天后给他们看样片，信任就会建立。书里还藏了一个反直觉的经验：给演员的任务越多，他们演得越好——当脑子被台词、走位、提示塞满，自我怀疑就没地方落脚，只能凭本能表演，而本能的表演最真实。若演员开始抱怨"这不符合角色"，那往往说明你已把他们推到了那个临界点，这是好兆头。

## 要点速记
1. 每个机位运动都要有一个动作当挂钩。
2. 身体朝相反、头各倾一点，双人同框也能写出矛盾。
3. 想让观众专心听台词，就给演员找点事做，别让他们对视。
4. 制造期待，然后转身，永远不给答案。
5. 用横向移位决定揭示次序。
6. 象征物要被角色亲手移开，隔阂才算破了。
7. 把任务加满，演员只能凭本能演——那是你想要的。

- **第9章（亲密感）**: 11.11 消除隔阂是 9.11 关联物的对立用法——一个用来靠近，一个用来隔开再拆掉。
