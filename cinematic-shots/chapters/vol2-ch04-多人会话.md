# 第4章：多人会话（《大师镜头 第2卷》）

## 核心思想
多人场景的唯一任务不是让人说话，而是让人在看谁。观众一旦掌握了"谁在哪、谁在看谁"，就自动掌握了话语权；你要做的是用站位、目光和景深把这张关系图钉进观众脑子里，然后尽量少切。

## 技巧框架
- **转身现人（4.1）**: 让一直沉默的人在被点名时转身／动一下，位置与发言同时被交代。
  - 何时用: 群戏中有人中途插话，观众此前没记住他站哪。
  - 怎么做: 先不要切到说话者，让他在原位置上做一个动作或转身；不切到对方近景，而是保留一个能看到所有人的关系镜头；让演员在对话中不断微调站位，场景因此有景深。
- **目光示人（4.2）**: 用所有人目光的汇聚，标示中心的发言者。
  - 何时用: 十几个人在场，只有一个人在讲，观众必须知道谁在听谁。
  - 怎么做: 让中心人物背墙站立、目光扫过全场；其他人全部望向他，脸可以在画面中间，但眼睛要斜向一侧，让目光方向成为构图主线；可用低机位仰拍两三个听者，且头部的倾斜角度一致；摄影机可以四处移动，但剪辑时用多拍的角度救场。
- **三人小组（4.3）**: 一个推镜把三人对话收进同一画面，不切。
  - 何时用: 三人环桌／环坐，其中一人是重点，另两人是反应。
  - 怎么做: 桌子朝镜头的一面空着；镜头缓推，三人同步前倾身体配合靠近；快到终点时向左转一个角度，对准另两人；焦点从说话者转到听者。一个镜头结束场景。
- **中心人物（4.4）**: 把被冷落的主角放在画面正中，让旁人聊天聊给他听。
  - 何时用: 主角在场却被排除在对话之外。
  - 怎么做: 广角、与头等高、正面对三人，主角居中但他话最少、最不起眼；另两个镜头里两位说话者分居画面最左与最右，把观众视线推向画外的他；两位说话者必须彼此盯视，不看主角，否则三人就"一起聊"了；用服装、体态等细节加重（他人赤膊抽烟、主角低头）。
- **排成一列（4.5）**: 三四个人排成一条斜线，一次看清所有脸。
  - 何时用: 场景自然呈线性（吧台、柜台、一排椅子），又想少剪。
  - 怎么做: 离镜头最近的人背向主线（给个理由，比如手里端着东西）；让最近的人转身面向镜头并指向某处，之后所有人转过来听；从三人主镜头直接切两人的中景，而不是逐个切单人特写。
- **一行三人（4.6）**: 三人并肩望向远方，让"露脸顺序"成为节奏。
  - 何时用: 三个人共同注视画外的东西（阳台、海面、观众席）。
  - 怎么做: 三人一条斜线、与摄影机成小角度，同向看；不要按顺序依次露脸（会变喜剧），让中间的人先露头，再让最近的人，最后让最远的人说话；远处的人说话时，中间的人不转头看他，画面才不会空。
- **中心线（4.7）**: 群戏里的双人对话，仍用最朴素的正反打，只是退远些。
  - 何时用: 一屋子人，但真正的对话只属于两个人。
  - 怎么做: 机位不贴脸，要能带到全场所有人，让次要角色插话时被看见；摄影机严守两人连线的同一侧；除了补必要的连贯镜头，不要切特写。若同一场景在片中重复出现，保持完全相同的角度，只用服装等小差异标注时间。
- **静止镜头（4.8）**: 摄影机与主角都不动，让周围人动。
  - 何时用: 有一个气场极强的角色被众人围着（崇拜、慌乱、逼问）。
  - 怎么做: 长焦从远处拍，糊掉背景；主角只转头，其余人围绕他走动、来回看他；用一次有力的出入画动作收尾（有人走向镜头或背向镜头走开），否则下一镜会突兀。
- **圆桌会话（4.9）**: 用"同一个中心人物的左右两版"帮观众记住方位。
  - 何时用: 一桌人围着圆桌，必须让观众知道谁是主角。
  - 怎么做: 开场先给全桌位置图；主角给最强光、最大动作、身体朝镜头倾；接着一个镜头他在画面右端望左，另一个镜头他在左端望右，同一场戏给左右两版；说话者不要正对镜头，望着一旁；插特写之后一定要切回关系镜头。
- **增加成员（4.10）**: 让背景里的人陆续走到前景，成员在一个长镜头里聚齐。
  - 何时用: 会议、聚会，人物要逐渐到齐。
  - 怎么做: 开场是主角特写，对话在他身后；摄影机在轨道上缓慢后退，背景演员趁机走到他身边靠近镜头，再退回背景，往复，直到全员聚拢；主角始终是构图中心，周围人要显得是来向他索取信息。下一镜是静态就让它停稳后再切，下一镜是动态就在运动中切。

## 关键概念
- **关系镜头**: 一个画面里同时容得下多人及其相互位置，观众靠它建立空间记忆。
- **目光方向**: 比脸的位置更可靠的构图线索，能指向画外的人与权力中心。
- **露脸顺序**: 并列人物的出场次序本身就是节奏与信息控制。
- **中心线（假想连线）**: 双人对话的轴线，群戏里同样要守。
- **重复角度**: 同一场景在片中反复出现时，用完全相同的机位强调"物是人非"。
- **出入画收尾**: 用一个有方向的物理动作结束静止场景，给剪辑一个接口。

## 心智模型
- 当人多到无法逐个照顾时，把"谁在看谁"拍清楚，剩下的观众自己会补。
- 把群戏当作一张地图：每一次切镜都是在给观众重画地图，重画越少越好。
- 当主角被冷落，让他居中；当主角被拥戴，让他不动。
- 当你要表现"什么都没变"，用同一个机位再拍一次。

## 反模式
- **一个主镜头＋每人一个近景**: 最省事也最无聊，观众还会搞不清谁在跟谁说话。
- **插话前不交代位置**: 突然开口的人让观众瞬间出戏——先让他转身或动一下。
- **圆桌戏全用特写**: 位置关系彻底丢失，观众记不住谁坐哪。
- **三人并排按顺序依次露脸**: 会掉进喜剧节奏。
- **被冷落者的同伴互不注视**: 一旦他们看向主角，三人就变成一桌朋友，孤独感消失。
- **静止场景用一句台词收尾**: 结尾没力量，下一镜必突兀。

## 实例解析
《慕尼黑》（4.10 增加成员）：开场是主角的近景特写，别人的对话在他身后进行，说的是什么不重要，重要的是他脸上的反应——所以背景虚化也无妨。摄影机在轨道上缓缓后退，背后的人一个个走上来，靠到他身边贴近镜头，又退回背景，如此往复，直到所有人聚到他周围，摄影机同时抵达终止位置。整个过程没有一次剪切，观众既看清了每张脸，也看清了他是这群人的中心。

## 要点速记
1. 先给一次全员关系镜头，之后再谈特写。
2. 插话的人先动，再开口。
3. 群戏守轴线，退远一点，别贴脸。
4. 主角即便不说话，也要给他最强的光和最居中的位置。
5. 并列人物不要按顺序露脸，打乱次序。
6. 静止场景必须用一个有方向的出入画动作收尾。
7. 想表现时间流逝而人事未变，就复用同一个机位。

## 关联
- **第2章（紧张气氛）**: 2.6 同一侧是把双人构图故意拍歪；本章是把多人构图拍清，两者互为反面。
- **第5章（建立联系）**: 三人小组、中心人物这些布局在"初次见面"的场合会转为建立关系的工具。
- **第9章（亲密感）**: 4.6 一行三人的"同向注视"在亲密场景中会变成两人共同的视点。
