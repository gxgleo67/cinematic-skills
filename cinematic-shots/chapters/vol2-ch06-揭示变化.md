# 第6章：揭示变化（《大师镜头 第2卷》）

## 核心思想
信息落地的那一刻必须有可见的位移：人换高度、换位置、换光线、换焦点。观众记得住的不是台词说了什么，而是说完之后画面变成了什么样。

## 技巧框架
- **高度变换（6.1）**: 用上下台阶让"决定"变成可见的动作。
  - 何时用: 场景中有人要做决定，情节即将推进。
  - 怎么做: 开场两人在楼梯上下分开站，构图开阔能看到脸；一人下楼梯、另一人上几个台阶，摄影机跟着上台阶的那位并轻微推近；她转身说话时脸留在画面内，另一人暂时出画也无妨——焦点在决定，不在他的反应；她再走下台阶回到两人中间，此时重点转为看他们的反应，她背对镜头也成立。
- **近距离接触（6.2）**: 一次跳接切到对面，只改角度不改距离与焦距。
  - 何时用: 重要信息出现，需要两人同框且脸都看得清。
  - 怎么做: 第一个镜头对焦在两人共同看的物件（信、照片）上，脸偏着但不清；切到正对面，机位距离与焦距都不变，于是两人距离在观众感觉中瞬间缩短，不得不对视；给他们一个身体接触的理由（一人靠在另一人身上），近才不别扭；整场只剪一次。
- **强烈对比（6.3）**: 把切点落在秘密说出口的那一帧，并切到完全相反的角度。
  - 何时用: 台词本身是转折，需要剪辑替它加重量。
  - 怎么做: 让两人朝镜头走一段长路，镜头一直不给对视；其中一人努力寻求眼神，另一人不理不躲；当他们停下相对而立、第一次对视的瞬间，切到反方向（两人在画面中左右互换）；光线同时从打足变成剪影，仿佛一同进入秘密的世界。
- **面对面（6.4）**: 让透露信息的人绕到侧面，再退回原位，把中心交出去。
  - 何时用: 有人必须说出关键信息，但情绪中心属于另一个人。
  - 怎么做: 两人面对面站；说话的人走到对方的一侧，让镜头能拍到他的脸，同时摄影机推近，让这个走位显得自然；信息说完他退回原位并弯腰仰视她，她低头几乎正对镜头——观众的情绪落在她身上。
- **脸朝上（6.5）**: 一动两静，用唯一的推镜标出"知道秘密的人"。
  - 何时用: 一个场景里有人知道得更多，需要暗示而不说破。
  - 怎么做: 开场用广角从高处俯拍，把两人不寻常的姿态（懒散地倒在沙发上）与空间关系一次说清；随后两个镜头都静止，只有朝知情者的那一个缓慢推近。若两个都推，信息就变成"两人都知情"。
- **背景转换（6.6）**: 让不安的人穿过房间，用一个摇拍改变他的位置与背景。
  - 何时用: 有人犹豫着要不要说出疑虑。
  - 怎么做: 开场让他背对摄影机，写出抗拒；另一人面对镜头提问，随后走到一侧坐下；第一个人起身穿过画面去接水（一个非必要的动作），摄影机原地摇拍跟随；全程机位不动，只靠走位与背影角度制造不安；他仍略背对镜头，只小心地瞥一眼对方。
- **无形的障碍（6.7）**: 用门框与"不转身"造出一堵看不见的墙。
  - 何时用: 两人互有好感，但关系必须被压住。
  - 怎么做: 一人背对镜头，只转头看她，身体不转正；她倚在门边、面朝他却不进房间，门框成为她不能逾越的界线；两人各给单独镜头，不用过肩，进一步把他们分开；最后一个镜头用长焦给出一点亲近感，但身体朝向仍然别扭。画面与情节指向相反方向，深度就出来了。
- **无须眼神交流（6.8）**: 用"不看对方"表现熟稔。
  - 何时用: 老朋友、老夫老妻式的自在对话，情节平淡需要质感。
  - 怎么做: 第一个镜头交代两人位置，让一人望向画外，从而两张脸能同框；随后正面各拍一个，全程不交换目光；把两人置于不同高度，让他们在物理上无法对视；即便有人瞥一眼也得不到回应——距离感不是冷淡，而是亲近。
- **转到背景（6.9）**: 让角色从模糊的前景走到清晰的背景，把反应交给焦点。
  - 何时用: 转折不在台词，而在某个人听完之后的表情变化。
  - 怎么做: 给角色一个日常忙碌的理由（洗碗、收拾），让她自然地端东西走到后景、面向镜头；在那里停下来"想一想"，同时她的脸从虚变实；用日常场景包裹转折，意外感更强。提前和录音部门沟通走位。
- **角色间摇拍（6.10）**: 在两人之间摇，最后让两人同时入画定格。
  - 何时用: 对话内容与背景中发生的表演互为注释，需要兼顾。
  - 怎么做: 摄影机在两人之间来回摇，背景可虚；结束时让两人同时前倾，摄影机做最后一次移动，在他们同时入画时停住；机位要略靠其中一人（主角），若居正中，停住时只能对着空背景；让坐得较靠后的演员能给出完整正脸；开拍前多排练，找到每个人的最佳角度。

## 关键概念
- **信息落点**: 关键信息被说出的那一帧，剪辑、光线、机位都该在这里变化。
- **反方向切**: 切到完全相反的角度，两人在画面中左右互换，最直观的"关系已变"。
- **静动配比**: 一动两静、一静一推，用运动的不对称标出谁掌握信息。
- **无形障碍**: 门框、身体朝向、单人中景，这些看不见的东西比实墙更能隔离两人。
- **焦点位移**: 从虚到实的焦点变化，等于给观众一个"现在请看她的脸"的指令。
- **日常动作掩护**: 洗碗、接水这类非必要动作，是走位与转折最好的伪装。

## 心智模型
- 当一句台词要改变关系，就让它落在一个机位也改变的位置上。
- 把楼梯当作情节的刻度：上一步是进，下一步是退。
- 当你想让观众只注意一个人，就让画面里只有他在动（或被推近）。
- 想表达"亲近但无法靠近"，用门框和不肯转正的身体，而不是台词。

## 反模式
- **两个镜头都推近**: 观众会以为两人都知情，秘密的归属被抹平。
- **在秘密说出口时仍用同一角度**: 转折被平掉，观众只觉得"他们聊完了"。
- **为了拍全每个角度而反复切**: 情绪被打断；简洁优雅的单镜头更有效。
- **近距双人镜头没有身体接触的理由**: 演员别扭，画面立刻假。
- **摇拍机位居中**: 停住时对着空背景，两人无法同时入画。
- **把转折放在正襟危坐的场景里**: 缺少日常质感，转折显得刻意。

## 实例解析
《一九八四》（6.3 强烈对比）：两名角色朝镜头走了很长一段路，全程不对视，其中一人反复试图捕捉对方的目光而不得。就在他们停下、第一次真正对视的那一瞬，导演切到了完全相反的方向——两人在画面里左右互换——同时光线从充足变成只剩剪影。观众看到的不只是"他说了秘密"，而是"他们一起进入了另一个世界"。这次剪切之所以有力，是因为它落在观众最不预期、情绪最饱和的那一帧。

## 要点速记
1. 关键信息要用画面变化来标记，不要只靠台词。
2. 想让观众惊讶，切点放在"第一次对视"那一刻。
3. 一动两静，或一静一推：运动的不对称就是信息的不对称。
4. 楼梯、门框、台阶都是免费的高度与界线装置。
5. 独自透露信息的人，说完要退开，把画面让给听者。
6. 用日常动作掩护走位，转折会更突然。

## 关联
- **第2章（紧张气氛）**: 2.4 戏剧性转向同样靠"延迟给脸"，本章把它用于信息揭示。

- **第10章（远距离交谈）**: 6.7 无形的障碍在远距离场景里升级为整套空间阻隔方案。
