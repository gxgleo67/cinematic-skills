# 第十一章：高级导演技巧（《大师镜头 第3卷 导演视野》）

## 核心思想
前九章的技巧都能拆成"机位＋运动"，本章问的是更前置的问题：这场戏为了让观众看懂，必须先给他们什么、按什么顺序给。真正的分水岭不在一只镜头用得多巧，而在开机前是否已经把"故事点—顺序—观众方位"想清楚；想清楚了，最朴素的推轨就够用。

## 技巧框架
- **纵深的演员调度**: 让背景的运动为摄影机运动提供动力与纵深。
  - 何时用: 场景要求"有事正在发生或将发生"；两人中景之间的空隙不知该放什么。
  - 怎么做: 把已付费的布景全部用上（机场的飞机、跑道的卡车）——这跟预算无关，跟在现场怎么看有关；让背景中的车辆／人朝不同方向穿行，每一次入画都给机器一个转向或推进的理由；让一辆车从机器身后开进画面中央，与推轨同向同速；同时它会填满两个演员之间的空隙。原则：焦外移动是填补双人镜头空白的最佳选择——完全空着枯燥，太有趣则抢戏。
- **激发摄影机**: 让画面里的一件事（道具、手的动作）牵引机器，而不是导演想拍哪儿就拍哪儿。
  - 何时用: 需要从一件小事长出一个揭示；演员在沉默中表演。
  - 怎么做: 一人弯腰挖胡萝卜，在萝卜被拔出的那一刻机器随之上升，一路升到她的脸；或一人从马上解下布条，展开时手横过画面，机器顺势右移，他转身与机器同向，最后跟着他的手落进衣袋。若硬要"先拍动作、再仰拍脸"，观众会在等待机器停下时出现心理中断，并注意到机器本身。前提：道具必须是故事里该出现的东西，不能为了给机器找动机而硬塞。
- **发展中的运动**: 不要全片匀速游移，要给运动本身安排节奏曲线。
  - 何时用: 手持长场景、情绪爆发段落。
  - 怎么做: 先让机器固定、由演员在画面内移动（他成为唯一的动作来源）；当他转身面向镜头后面的人、并朝镜头冲来时，机器也冲向他——速度极端的一下；但结尾必须把运动收回，否则这一下就废了；反之若全场都这么快，结尾那一下也就不成立。持续不变速的运动会让观众昏睡，就像纪录片作者围着拍摄对象乱转。
- **空间利用**: 别把动作摆在房间中心。
  - 何时用: 进入一个新的外景地，需要决定演员站哪儿。
  - 怎么做: 房间中心看起来最"自然"，也最像我们平时见惯的画面，因此最容易平庸；把演员靠墙、靠窗、靠桌，让其他人从前景穿过画面填充，避免他显得孤零零；让背景布满细节，并且用前景细节（一截衣袖）把注意力挂在画面里；若要交代整个空间的面貌，就得离开主体很远、用超长焦在场地里横向移动——此时角度选择决定一切：让他朝镜头跑来就不会有摇摄，让他横着跑过就会把背景摇糊。
- **迷失的布局**: 多人场景的前十秒决定观众之后能不能看懂。
  - 何时用: 一桌人、一屋子人、多方对话。
  - 怎么做: 开头用一个运动把座位关系交代清楚：让主角的手臂伸过画面中央，观众的视线自然被拉到那里；即使他不在这个镜头里，也让他的一截衣袖留在画面中当方位锚点；切到桌子另一头时，务必让他的脸还在画面内。只要观众始终知道"他坐在哪"，就能跟着他的视线切到任何角落；反之把各人的对话镜头乱剪在一起，观众不知道谁在对谁说话，会被复杂性激怒。用一个人的视线给一次剪辑提供动机，再小的运动也能防止迷惑。
- **演员视野**: 让观众看到"她在看什么"，而不用真正的视点镜头。
  - 何时用: 秘密的注视、暗恋、窥视；对象私密或重要。
  - 怎么做: 方法一：先对着空荡的门口缓推，制造"想往里看"的好奇；随后主角出现在我们前面、同样对着门口，她们转身往里看时，我们与她们看同一方向——不是通过她的眼睛看，而是与她看同一处，因此知道自己在看她所看之物。方法二：长焦拍远处的男孩，前后景全部虚化，使他们注定成为"被注视的对象"；切到两个女孩，让她们以倾斜的角度坐着、转头越过镜头去看——若坐正面对镜头，"在看"这件事就不明显，甚至会像换了一场戏；最后让其中一人移开目光、另一人仍在看，把她单独分离出来，观众便明白这是她的场景。
- **故事点**: 一个镜头里按顺序交付全部关键信息。
  - 何时用: 解释性的段落（有人在处理某物、某件事正在被安排）。
  - 怎么做: 先列出"观众必须看到什么"和"看的顺序"，再让运动把它们串起来：隔着门缝看到被绑的马（第一个故事点）→ 机器后退、门打开，有人进入马匹的区域 → 机器抬高，看到他手里的绳子，另一人跟着、也拿着绳子 → 继续后拉，门已关上、马开始反应。一个后拉镜头就把"人们接近马匹、不情愿地套上马具"讲完；随后两个短镜头给绳子套上鼻子的细节，马被带走时机器前推，否则会沉闷。
- **场景调度**: 长镜头要服务于表演，而不是让演员为长镜头服务。
  - 何时用: 一场戏的张力需要长时间不切；演员要反复重复一段长调度。
  - 怎么做: 把"引入场景"与"长对话"拆成两个镜头，演员不必为一条完美的长镜头反复消耗；两个镜头之间让演员在画框中处于大致相同的位置，剪起来像连续的；对话进行时机器逐步逼近他们；让屋内的一家人从房里走出、正好站在两个男人之间——这既是构图也是象征；有人跑出画面，焦点便自然落在剩下的两人身上；结尾跟着两人走、把他们推到画框右侧，制造"事情尚未完结"，再让一个女孩跑进来插到他们中间，强化这个未完感。若场景更适合特写与紧凑剪辑，就不要为"看起来很厉害"而用长镜头。
- **视觉化场景**: 以视点演员的情感体验为轴心来设计整个段落。
  - 何时用: 主角被侵入、被剥夺、被围困的段落。
  - 怎么做: 先问"这是谁的故事、她此刻感到什么"，再让每个技术选择服务于此：让她穿着浴袍开门（毫无准备、脆弱、以家为中心），与门外制服人员形成冷硬对比；她即使开了门仍把自己藏在门后；背景虚焦，像是她试图把屋内藏起来；来者推门而入时他占据画面、也接管了她的房子，他进屋的速度快得略不真实——这点失真恰好外化她的失措；她居中，但背景里始终有人、或有人从前景经过，她被包围；他离开的镜头顺手带出锁匠正在换锁（一个故事点），而最后给她的机位几乎让观众直视她的眼睛。
- **即兴发挥**: 现场找不到镜头时，先让演员用最简单的方式演一遍。
  - 何时用: 时间紧、场景陌生、不知道重点在哪。
  - 怎么做: 让演员在场景里自然站位演一遍，你在旁边看自己的注意力被什么吸走——那就是该强调的东西；用演员的创造力滋养你的判断，但如果他们的方向偏离整体视觉构想，要把他们拉回来，不要让他们在自己的路上走远；随后再用手持、短促的前后运动去"寻找"兴趣点，直到画面出现。这种风格不适合大多数影片，但它能给你产生镜头想法的起点。开拍前仍要清晰想象出最佳镜头；到现场后记住：摄影机不是用来"捕捉"的，而是用来"解释"场景的。

## 关键概念
- **方位锚点**: 一个始终可见的人或物（一截衣袖、一张脸），让观众在多机位里保持方向感。
- **故事点序列**: 观众必须看到的信息及其呈现顺序；镜头的设计从这张清单开始。
- **运动的动机**: 画面内某物的运动为机器提供理由；反之则暴露导演。
- **节奏曲线**: 运动要有静止、加速、回收，不能匀速到底。
- **解释而非捕捉**: 摄影机的作用是诠释场景意义，不是记录表演。
- **视点演员**: 观众被要求与之共情、并借其眼光看世界的那个人。

## 心智模型
- 拍摄前先写"这张清单"：观众必须看到什么、按什么顺序；然后让运动去串它。
- 把一截衣袖当路标：观众只要认得出他在哪，就敢跟你去任何角落。
- 当运动没有动机时，去找画面里该动的东西，而不是推机器。
- 把长镜头当成本项：只有当"长时间的张力"值得这笔成本时才用。

## 反模式
- **动作摆在房间正中**: 最自然也最平庸，画面没有任何可读的背景。
- **背景空无一物或过分有趣**: 前者枯燥，后者抢戏；焦外的移动才是正解。
- **匀速游移的手持**: 观众昏睡，且看不出重点。
- **多人场景不做方位交代**: 观众被复杂性激怒，直接退出故事。
- **为炫技用长镜头**: 演员被反复消耗，最终表演反而变差。
- **先想机位再想故事点**: 顺序错了，再漂亮的运动也讲不清事。
- **把摄影机当记录仪**: 只捕捉不解释，场景就没有观点。

## 实例解析
《荒岛余生》那场餐桌戏看似由多个角度无缝拼接，实则是精确设计的结果。开场机器跟着某人进入餐桌，观众只来得及形成一个大概的座位印象——因为主角的手臂横过画面中央，视线被强行拉到那里；接下来的镜头里他甚至不在画中，但一截衣袖留在画面里充当路标，观众因此仍知道其他人是在对谁说话。切到桌子另一端时，他的脸始终在画内。整场戏的艰苦工作全部集中在开头十几秒：一旦观众记住了谁坐在哪，后面就可以按"谁在说话"自由剪辑而不引起任何迷惑。这正是本章的核心——把设计成本压在前十秒，换来整场戏的自由。

## 要点速记
1. 开拍前列出故事点清单和顺序，再决定镜头。
2. 前十秒交代座位关系，后面才能随便剪。
3. 让一个人的脸或衣袖成为全场方位锚点。
4. 背景用焦外的移动填补，别空着也别太抢眼。
5. 机器运动必须由画面里的东西激发，否则观众会看到导演。
6. 手持长场景要有节奏曲线：静止—爆发—回收。
7. 长镜头要付得起成本：演员的耐心也是预算。
