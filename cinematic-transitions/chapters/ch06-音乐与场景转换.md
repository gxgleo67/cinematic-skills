# 第6章：音乐与场景转换（《大师场景》）

## 核心思想
音乐在转换处只做四件事：为下一场筑张力、消减上一场的张力、呼应上一场的情感、为下一场设定情绪。而比音乐更重要的是静默——静默是作曲家最强武器，也是让响亮的音乐重新有力量的对比基准。

## 技巧框架
- **静默**: 静默不等于没有音乐，而是经过计划的空白，提供空间感与真实感，让观众与事件保持距离。
  - 何时用: 转换要跳到情绪与环境完全不同的画面时；需要观众自己判断时。
  - 怎么做: 先把静默当作画布，再决定声音往哪边铺；静默与沉默并列时，不要用环境声填满，否则对比消失。
- **作为润滑剂**: 音乐在转换处主要掩盖剪辑痕迹，像机器里的润滑油，减少"技巧摩擦"。
  - 何时用: 跳切明显、剪辑点偏早或偏晚、空间跳跃生硬时。
  - 怎么做: 让配乐步调与镜头剪辑同步；音乐通常早于真正的场景边界进入，先把观众送过去，再换画面——它比叠化更柔软，效果几乎等同。
- **推动或缓解张力**: 音乐性张力在场景连接处升到顶点，然后在场景B开头退去，像浪退出沙滩。
  - 何时用: 决定这一刻该把观众推入下一场，还是让他们喘一口气。
  - 怎么做: 缓解用松弓弦式的下行与释放（等同于"揭示新内容"）；推动则只释放一部分张力，随即在新方向上继续加码——不要一次把弓拉空。
- **运用音乐讲故事**: 音乐不表现主人公的感受，它规定观众该怎么感受。
  - 转化: 音乐把上一场的情感捕捉、传送、重塑，让观众与素材发生交流。
  - 增加背景: 用音乐给场景定性，把中性的画面导向某个世界观。
  - 设定情绪: 用时代、地域、风格的音乐唤起观众的文化记忆。
  - 重温主题: 用与人物绑定的主题动机（《大白鲨》的鲨鱼、《星球大战》的帝国）在场景开头即刻唤起前情。
  - 何时用: 画面已经拍完、但你需要改变观众对它的理解时（《变脸》在警匪枪战上叠一首童声《彩虹之上》，以剧情声从孩子耳机里传出，视角立刻切到孩子，主角变成保护者，FBI 变成施暴者）。
- **转化策略的四种变体**: 在场景变化的精确瞬间画一条线，线两侧的声音只有四种组合，效果各不相同。
  - **静默→音乐**: 累积的压抑得到释放，是宣泄，把上一场的情感升华并延续。
  - **音乐→音乐**: 情感持续增强或恶化（从坏到更坏），通常用于保持并强化能量。
  - **音乐→静默**: 迅速抽掉音乐，制造对即将发生之事的预期；同时不强加解释，把诠释权交还观众。
  - **静默→静默**: 上一场的情绪既不消散也不释放，节奏被维持住。
  - 何时用: 你已决定"这场该带情绪过去"，接下来选哪一变体。
  - 怎么做: 先定要不要延续情绪（延续＝音乐跨线），再定要不要给观众自由（给自由＝收在静默上）。
- **预先计划与最小化配乐**: 最小化的配乐只提供声音环境、不承担情感，它能非常自然地融进场景，作用接近静默。
  - 何时用: 不想让配乐显得在"推"观众时。
  - 怎么做: 让音乐退成氛围层，把情感交给表演与剪辑。
- **使用预录歌曲**: 拍摄前已存在的歌曲，剪辑反过来去匹配它的节奏；它比原创配乐更容承载时代与集体记忆。
  - 何时用: 开场、拼贴段落、蒙太奇、需要时代标识时。
  - 怎么做: 让歌曲在重大事件后进入，替主人公释放情绪，转换完成时在下一场开头渐渐淡出；音乐加入时剪辑成为歌曲节奏的一部分（反向不成立）。
- **歌词的作用**: 歌词像叙述者，或替人物说话，或评论正在发生的事，把观众带离故事、进入更客观的立场。
  - 何时用: 需要给主题与动机加注解、又不愿用台词说破时。
  - 怎么做: 选诗性、可多层解读的歌词；即使观众听不清词，人声也会把情绪带到别处（《毕业生》开场用《寂静之声》把本杰明的内心独白外化，一次就定下"这人无法融入周遭"的基调）。

## 关键概念
- **静默**: 计划中的空白，是配乐的一部分而非缺席。
- **润滑剂**: 音乐在转换处减少剪辑摩擦的功能。
- **四种声音变体**: 静默→音乐 / 音乐→音乐 / 音乐→静默 / 静默→静默。
- **剧情声（diegetic sound）**: 故事世界里有音源的声音，可写进剧本（孩子耳机里的歌）。
- **主题动机**: 与人物或势力绑定的重复音乐主题。
- **最小化配乐**: 只提供环境、不承担情感的音乐层。

## 心智模型
- 把静默当作**画布**，音乐是画上去的颜色；画布越小，颜色越响。
- 当你要观众"自己判断"时，收在静默上；当你要观众"跟着走"时，让音乐跨过剪辑点。
- 把歌词当作**第二个叙述者**：它在替谁说、在评论什么，先答出来再选歌。
- 当画面已经很好、音乐却让一切变笨时，删音乐，不要改画面。

## 反模式
- **全片不停铺音乐**: 没有静默作对比，最响的那一段也不响；观众被持续安抚，感受力下降。
- **音乐解释过度**: 用夸张配乐替人物补情绪，信息给太多，观众反而分心。
- **音乐与画面同向到底**: 悲伤画面配悲伤音乐，观众提前知道答案，不再参与。
- **用音乐硬盖剪辑问题**: 剪辑点错了就加音乐，长期会让整片节奏失去支点。
- **把歌曲当背景音**: 不设计进出点、不让它承担叙事功能，等于浪费一次时代与情绪的机会。

## 实例解析
《角斗士》里马克西姆斯被康茂德背叛、押赴刑场的那一整段几乎没有音乐。这不是省预算，而是人物性格的写法：他冷静、务实地面对绝境，此时若配上悬疑或悲壮的音乐，反而会替他说出他没说的话，也削弱他逃脱时的惊奇。直到他杀死守卫、夺马逃入森林，音乐才终于响起，并从他"一直被压抑的内心"里长出来——先前听不见的，此刻才让观众听见。这就是"静默→音乐"的宣泄变体：不是音乐制造了情绪，是静默先把情绪压住，音乐才得以释放它。

## 要点速记
1. 先决定这一刻要不要音乐，再决定要什么音乐。
2. 转换处画一条线，明确声音是跨线还是断线。
3. 想让观众自由判断，就用"音乐→静默"；想宣泄，就用"静默→音乐"。
4. 音乐提前于画面进入，可以替代叠化。
5. 用主题动机在场景开头一秒唤起前情。
6. 预录歌曲的剪辑要跟着歌走，不是让歌跟着画面走。
7. 每一场都铺满音乐时，回来删掉三分之一。
