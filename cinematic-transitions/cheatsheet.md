# 决策速查（《大师场景》）

## 一、决策规则：当 X，做 Y，因为 Z
| 当…… | 做…… | 因为…… |
|---|---|---|
| 不确定这个转换要不要装饰 | 用硬切 | 注意力是稀缺资源，明显手法要留给六节点 |
| 场景结尾要让观众"在乎" | 信息＋人物反应，同一瞬间叠加 | 只有情节张力没有情绪化＝观众知道但不动 |
| 重击之后的下一场不知怎么开 | 撤掉新情节，先给景物与背景声 | 观众的心理能量全在消化上一场，此刻给信息必被错过 |
| 观众可能分不清"换场了" | 让新场第一印象与上一场最后印象成对立 | 界线靠对比确认，不靠字幕解释 |
| 观众跟丢了因果 | 先补因果钩子，再谈视觉花招 | 视觉钩子漂亮但脆弱，因果朴素但可靠 |
| 想让观众自己判断、不要被指引 | 音乐收在静默上 | 保留声音＝替观众下结论，抽掉声音＝交还诠释权 |
| 想让观众被推着走 | 让音乐早于画面跨过剪辑点 | 音乐先把观众送过去，比叠化更柔软 |
| 全片每个转换都一个样 | 写出五参数序列，检查交替与渐强 | 节奏来自差异，不来自手法本身的精巧 |
| 一场戏"很好但连起来不对" | 改融合（长度／张力／情绪），别改戏 | 问题在接缝，不在场景内部 |
| 舍不得删一场戏 | 先问"删掉会不会更强"，再试四个替代 | 省略本身就是表达，不是省事 |
| 观众开始看表 | 找缺失的舒缓，而不是加情节 | 疲劳来自持续高张力，不来自信息不足 |
| 短视频／移动端为主 | 少广角、快剪、多特写 | 小屏上广角丢细节，大尺度只剩"理性欣赏" |

## 二、决策树：这个缝该用什么？
```
这场戏的顶点在哪里？
├─ 就在场景结尾（投入）→ 让反应跨过边界 → 选声音：
│   ├─ 要宣泄 → 静默→音乐
│   ├─ 要加压 → 音乐→音乐
│   ├─ 要观众自己判断 → 音乐→静默
│   └─ 要维持节奏 → 静默→静默
└─ 不在结尾／需要观众回味 → 边界怎么切？
    ├─ 要清空因果、重启段落 → 切黑（可插字幕）
    ├─ 要推向高潮、当下过曝 → 淡到白
    ├─ 要慢下来、表现"很久" → 叠化
    ├─ 要保留速度又有流动感 → 划变（匹配运动方向）
    └─ 要快、要果决 → 硬切
```
选完边界，再问一次：**这个转换值得被看见吗？** 不在六节点上，就退回硬切。

## 三、权衡矩阵
| 手法 | 成本 | 效果 | 用错时 |
|---|---|---|---|
| 硬切 | 最低 | 快、果决、可读作麻木 | 关键瞬间被浪费 |
| 叠化 | 低 | 软、沉思、释放张力 | 显得陈旧、拖慢节奏 |
| 划变／赖特划变 | 中 | 流动、作者印记、节奏感 | 观众只看转场不看戏 |
| 切黑 | 低 | 段落重启、清空关联 | 影片失去向前的动力 |
| 淡到白 | 中 | 当下极致强度 | 温度不对时做作 |
| 交通场景 | 高 | 共情、呼吸、反应 | 重复使用即收益减半 |
| 拼贴／嘻哈蒙太奇 | 中高 | 压缩时间、段落爆发 | 连续使用令观众疲惫 |
| 超长转换 | 最高 | 一次身份／世界的整体位移 | 没有节拍变化就变成拖沓 |

## 四、经验数值
- **场景量级**：剧情片约 40–200 个场景、10–30 个段落、1–30 个场所；交叉写作的剧本名义场数虚高（126 场实际约 40 场）。
- **值得精工设计的转换**：20–30 个；**明显转换**：6 个（开场、第一幕结尾、第二幕中段、第二幕结尾、高潮之后、离场）。
- **场景长度**：1960 年前平均约 3 分钟，之后短于 3 分钟，当代好莱坞有整片平均 1 分钟的；向高潮推进时自然变短。
- **低潮窗口**：场景开头 30 秒–1 分钟不给新情节。
- **广告间歇**：约每 5 分钟一次外部中断，情感转换要放进节内而非节尾。
- **收益递减**：同一技巧第二次的效果约为第一次的一半。

## 五、快速识别信号
- 观众说"看不懂"而非"不好看" → 关联／心理地图缺失，不是节奏问题。
- 观众说"拖" → 低潮伪装失败，或转换过长而节拍没变。
- 观众说"平" → 缺投入叠加，或全片只有一个情绪。
- 你自己记不住第 12 场怎么接第 13 场 → 没有钩子，先补因果。
- 重看时只注意到转场 → 强调程度超配，退回硬切。
- 结局再好观众也不在乎 → 中段没给过歇息，情感账户早已透支。
